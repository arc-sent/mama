# mother — инварианты

Бот готовит видео и выдаёт JSON-план в Telegram. VK, токенов и публикации здесь нет.

- **Дневная квота** (`scheduler.plan_rule`): N видео на *день выдачи* (`delivery_day`:
  сегодня до 12:00, иначе завтра). Считаются все строки `queue` на этот день, включая
  `delivered`, — поэтому выданные строки из `queue` не удаляются. Иначе рестарт или
  второй прогон задвоят выдачу.
- **Дедуп на правило**: `delivered(rule_id, tt_video_id)`; одно видео может уйти в разные группы.
- Видео, которое не скачалось, помечается `delivered` и снимается с очереди (не берётся повторно), ошибка — в `/errors`.
- Статус записи очереди: `pending` → `ready` → `delivered`. В JSON попадают только `ready`.
- Выдача: сначала успешный `send_document`, потом `save_plan` и пометка `delivered`.
  Если отправка упала — видео остаются `ready` и уйдут со следующим планом.
- Источники читаются **только на чтение** (`source_reader._connect_ro`).
- Обработка видео (`video_processor`) не должна срывать выдачу: при сбое уходит оригинал.
- Пауза (`/stop`) останавливает только автоматику; `/plan` работает всегда.
- Модули плоские (`import db`), запуск из папки mother. Ничего не импортируется из omega.

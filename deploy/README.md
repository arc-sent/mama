# mother на сервере (VPS) + ПК с браузерными профилями

```
VPS:  mother (Docker) ── скачивает видео, готовит план ── API на порту 8787 (токен)
                                       ▲  ▼   только исходящие соединения с ПК
ПК:   pc_agent/pull_plan.py ── план + видео ──▶ krug_upload ──▶ pull_plan.py report
```

ПК сам ходит на сервер, поэтому ему не нужен белый адрес. Если ПК был выключен, план ждёт на сервере.

## 1. Сервер

Нужны Linux, Docker и Docker Compose.

```bash
# с вашего ПК: залить папку mother (без .env и data)
scp -r mother user@SERVER:~/mother
ssh user@SERVER
cd ~/mother
cp .env.example .env && nano .env
docker compose up -d --build
docker compose logs -f
```

В `.env` на сервере:

| Переменная | Значение |
|---|---|
| `TELEGRAM_TOKEN`, `ADMIN_IDS` | как сейчас (`TELEGRAM_PROXY` на сервере, скорее всего, не нужен — уберите) |
| `MOTHER_API_TOKEN` | длинный случайный токен: `openssl rand -hex 32` |
| `KEEP_DAYS` | через сколько дней после отчёта ПК удалять видео (по умолчанию 2) |
| `DOWNLOAD_PROXY` | прокси для TikTok, если с IP сервера не качает |

База, источники, планы и видео лежат в `./data` и `./videos` рядом с `docker-compose.yml`
(они переживают перезапуск и обновление контейнера). Перенесите свою базу, если хотите сохранить
группы, источники и правила: скопируйте `data/mother.db` и `data/sources/` на сервер.

## 2. Как открыть API для ПК — выберите один способ

**A. Tailscale (проще и безопаснее всего).** Поставьте Tailscale на сервер и на ПК, войдите в один аккаунт.
API доступен по адресу вида `http://100.x.y.z:8787` (или по имени машины), и никуда в интернет не торчит.
Порт в compose привязан к `127.0.0.1`, поэтому замените строку `ports` на
`"100.x.y.z:8787:8787"` (Tailscale-адрес сервера) и перезапустите: `docker compose up -d`.

**B. Публичный HTTPS.** Нужен домен. Поставьте Caddy и используйте `deploy/Caddyfile`
(`reverse_proxy 127.0.0.1:8787`); API будет по `https://ваш-домен`. Токен длинный, порт 8787 снаружи
не открывайте (фаервол: только 80 и 443).

Прямой доступ к `:8787` по обычному HTTP из интернета не делайте: токен и видео пойдут открытым текстом.

## 3. ПК

Агент лежит в `Marionette\marionette\pc_agent` (описание — `pc_agent/README.md`):
скопируйте `.env.example` в `.env`, впишите адрес API и токен.

## 4. Проверка

```bash
curl https://ваш-домен/health                                   # {"ok": true}
curl -H "Authorization: Bearer ТОКЕН" https://ваш-домен/plan/latest
```

Без токена всё, кроме `/health`, отвечает 401.

## Что учесть

* **TikTok с IP сервера** нередко отказывает в скачивании: если в `/errors` бота видны ошибки скачивания,
  задайте `DOWNLOAD_PROXY`.
* Бот Telegram на сервере работает без прокси; на ПК с VPN он, наоборот, лучше не запускать одновременно с
  серверным — один токен нельзя опрашивать из двух мест. Остановите локальный бот перед переездом.
* Токен API лежит только в `.env` (в `.gitignore`); при утечке замените его и перезапустите контейнер и агент.
